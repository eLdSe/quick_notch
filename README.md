# QuickNotch (C# / WPF)

**QuickNotch** — это интерактивный виджет «Dynamic Island / чёлка» для Windows 10 и Windows 11, написанный на C# (.NET 8 + WPF) с собственной легковесной отрисовкой (`DrawingContext`) и физикой пружин (`Spring`).

Виджет располагается в верхней части экрана, отображает текущую музыку, уведомления, время и заряд батареи, а при наведении или клике плавно раскрывается в полноценный центр управления с ИИ-ассистентом и роботом-компаньоном **Aero**.

---

## ✨ Основные возможности

- **Центр управления (`Управление`)** — быстрый доступ к медиаплееру, громкости, погоде, системным действиям и виджетам в одном окне.
- **Медиаплеер (`Медиа`)** — интеграция с системными медиа-сессиями Windows (SMTC): обложка трека, название, исполнитель, прогресс-бар с перемоткой, переключение треков и анимированный эквалайзер в свёрнутом состоянии.
- **ИИ-ассистент и компаньон Aero (`Аэро`)**:
  - Поддержка провайдеров **Google Gemini**, **OpenAI** и **DeepSeek** (режимы *Fast* и *Pro*).
  - Возможность прикреплять скриншоты экрана и изображения в чат, сохранение истории диалогов.
  - Интерактивный робот-компаньон **Aero** с эмоциями, репликами и режимом свободной прогулки по рабочему столу (`AeroPetWindow`), где с ним можно общаться напрямую.
- **Буфер обмена (`Буфер`)** — автоматическое отслеживание истории скопированного текста с возможностью закрепления важных записей и быстрой вставки.
- **Быстрые ссылки (`Ссылки`)** — настраиваемая панель закладок для мгновенного открытия сайтов, папок и программ.
- **Календарь и заметки (`Календарь`)** — интерактивный календарь со списком задач и заметок на выбранный день.
- **Звук и устройства (`Звук`)** — управление системной громкостью, выбор аудиоустройств вывода и просмотр подключённых Bluetooth/аудио-устройств (через `NAudio.Wasapi`).
- **Погода (`Погода`)** — актуальная погода и прогноз по выбранному городу.
- **Система (`Система`)** — быстрые действия (блокировка экрана, сон, корзина, скриншот, диспетчер задач), режим «Не спать» (`Keep Awake`) и автозапуск с Windows.
- **Умные уведомления** — перехват системных уведомлений Windows, тосты при смене трека, подключении/отключении USB-накопителей и изменении статуса зарядки батареи.
- **Кастомизация (`Настройки`)**:
  - Стили острова: **Dynamic Island**, **Чёлка (Notch)**, **Компактный**.
  - Темы оформления: Тёмная, Светлая, Авто + выбор акцентного цвета и эффекта стекла (Glassmorphism).
  - Языки интерфейса: **Русский**, **English**, **Türkçe**.
  - Умное скрытие поверх полноэкранных приложений и игр.

## 🚀 Как запустить

### Вариант 1. Быстрый запуск из исходников (режим разработки)

Откройте терминал (PowerShell или CMD) в папке проекта и выполните:

```powershell
dotnet run
```

### Вариант 2. Сборка единого автономного `.exe` файла (Release)

Проект настроен на сборку в **один самодостаточный исполняемый файл** (`PublishSingleFile` + `SelfContained`), который не требует установленного .NET на компьютере:

```powershell
dotnet publish -c Release -r win-x64 -o publish_v2
```

После сборки готовый файл появится по пути `publish_v2\QuickNotch.exe`.  
Для его запуска можно также использовать батник `run.bat` в корне проекта.

## ⌨️ Управление и горячие клавиши

- **Раскрыть / свернуть остров**: клик по свёрнутому острову вверху экрана или глобальная горячая клавиша **`Ctrl + Alt + N`**.
- **Свернуть**: клик вне области острова (при включённой опции автосворачивания), клавиша **`Esc`** или кнопка `^` в правом верхнем углу.
- **Переключение разделов**: через нижний док или карточки на главном экране.
- **Выпуск робота Aero на рабочий стол**: клик по капсуле с роботом в шапке острова или переключение режима в настройках.

## 📂 Хранение данных и настроек

Все пользовательские настройки и данные сохраняются автоматически (атомарной записью) в папке профиля Windows:

```text
%APPDATA%\QuickNotch\
├── state.json        # Настройки оформления, поведения и API-ключи ИИ
├── links.json        # Быстрые ссылки
├── calendar.json     # Заметки и задачи календаря
└── aero_chats.json   # История диалогов с ИИ-ассистентом Aero
```

## 🏗 Структура проекта

| Файл | Описание |
| :--- | :--- |
| `App.xaml` / `App.xaml.cs` | Точка входа WPF-приложения, проверка единственного экземпляра (Mutex) |
| `MainWindow.xaml` / `.cs` | Прозрачное окно-хост поверх всех окон (`WS_EX_TOOLWINDOW`), хуки Win32 |
| `IslandView.cs` | Ядро острова: цикл анимации, обработка ввода, состояние и рендеринг |
| `Painter.cs` | Низкоуровневый графический движок поверх WPF `DrawingContext` |
| `Spring.cs` | Физическая модель пружинной анимации |
| `Sections.cs` / `Sections2.cs` | Отрисовка и логика вкладок (Управление, Медиа, Буфер, Звук, Погода, Календарь, Настройки и др.) |
| `AiSection.cs` / `AiService.cs` | Вкладка чата с ИИ и клиент для Gemini / OpenAI / DeepSeek API |
| `AeroPetWindow.cs` | Отдельное окно робота-компаньона Aero для прогулок по рабочему столу |
| `MediaService.cs` | Чтение метаданных и управление системным плеером через WinRT SMTC |
| `AudioService.cs` / `DeviceService.cs` | Управление звуком (`NAudio.Wasapi`) и список подключённых устройств |
| `NotificationService.cs` | Перехват системных уведомлений Windows |
| `SummonHookService.cs` | Отслеживание курсора у верхнего края экрана для вызова острова |
| `SystemService.cs` / `GlassService.cs` | Системные вызовы Windows, питание, автозапуск, эффект размытия |
| `StoreService.cs` | Чтение и сохранение JSON-конфигураций в `%APPDATA%\QuickNotch` |
| `Theme.cs` / `Loc.cs` | Цветовые палитры, темы оформления и локализация (`RU` / `EN` / `TR`) |
| `WinApi.cs` | Импорты функций Win32 API (`user32.dll`, `dwmapi.dll`, `kernel32.dll`, `shell32.dll`) |
